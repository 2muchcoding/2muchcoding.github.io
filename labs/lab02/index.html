Lab 2

In this lab, I built a professional resume webpage using HTML and CSS as part of my ITWS web environment. I set up the proper folder structure in my GitHub repository, worked with provided templates, and customized the content to reflect my own information. The lab emphasized semantic HTML, proper formatting, and using modern layout tools like Flexbox or Grid instead of tables. I also practiced version control with GitHub Desktop, tested changes locally with Live Preview, and deployed updates to my Azure server. This lab helped me create a foundation for a digital resume that I can continue refining and eventually share with employers.
