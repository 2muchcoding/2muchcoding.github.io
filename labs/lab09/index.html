Lab 9

In this lab, I developed a comprehensive web application for managing movies and actors using PHP and MySQL. The application features a multi-tab interface that allows users to add, view, and manage both actors and movies, as well as explore the relationships between them through a sophisticated relational database design. I was provided with a SQL file with the commands to create an actors table and insert some actors and also a PHP program which has a menu with two tabs. One will add/remove/display actors, however there is no table for the actors. The other is to do the same for movies, and while I was given the table, I was not given the code for the movies.php program. In this lab, completed the program so that we can Add/Remove and display both movies and actors.
